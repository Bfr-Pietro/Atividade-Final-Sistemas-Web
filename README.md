# Central de Chamados de TI | Prefeitura Municipal de São Miguel Arcanjo

Projeto final do 4º bimestre, Sistemas Web II. SPA em HTML, CSS e JavaScript puro, com as cores e o brasão do município.

- **Início:** apresentação, brasão, Missão/Visão/Valores em CSS Grid.
- **Listagem:** `fetch` + `async/await` na API JSONPlaceholder, dados no objeto global `estado`, cards, busca e filtros (status e secretaria). Botão para avançar o status do chamado.
- **Cadastro:** validação, `preventDefault()`, mensagens de erro/sucesso, inclusão imediata na listagem.
- **Navegação SPA:** troca de seções com a classe `.ativa`, sem recarregar. Os chamados cadastrados ficam salvos no navegador (localStorage).
